# 开发入门

这一节解决的是“还没开始写战术，就已经被环境和工具绊住”的问题。

请先建立下面这些共识：

- 我们的主开发平台是 **Windows + VS Code + MSVC + Qt 6 + CMake**。
- Python 环境统一放在 `ZBin/PythonScripts/.venv`，并由 `pyproject.toml` + `uv` 管理。
- 很多问题并不是算法问题，而是 **启动目录、解释器、PATH、git 工作流** 没有统一。

建议先读完本节，再去看架构和源码。

## 本节包含什么

- `Terminal 与 CLI`：为什么要会命令行，以及本项目里最常用的命令。
- `开发环境`：VS Code、`uv`、CMake、运行目录应该怎么配。
- `Git 工作流`：日常更新、提交、同步远端的推荐姿势。
- `设计模式`：读源码时最常见的组织方式。
- `状态机`：Play 为什么这样写，为什么一个状态机会牵动很多模块。
- `Munkres`：角色匹配为什么不是“谁近谁上”那么简单。
